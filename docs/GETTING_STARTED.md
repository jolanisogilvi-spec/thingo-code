# Thingo Code 快速开始

Thingo Code 是由 **Thingo** 开发的 AI 编程产品。本指南覆盖从安装、首次配置到开始完成真实项目任务的完整流程。

## 选择安装方式

### Windows 桌面版（推荐）

适合希望直接使用 Thingo Code 的用户。

1. 下载并安装 Thingo Code Windows 安装包。
2. 从开始菜单启动 **Thingo Code**。
3. 等待本地服务状态就绪，然后完成 LLM 配置。

桌面版已内置 Node.js、`uv`、Python 3.12 和后端依赖缓存。它不会根据你的系统 Python 版本重新解决依赖，因此在网络较慢或离线的机器上也能完成首次启动。

> 安装包未签名时，Windows 可能显示 SmartScreen 提示。只应从你信任的发布渠道下载，并核对发布者提供的 SHA-256 哈希。

### npm 命令行

适合已配置 Node.js 22.12.0 或更高版本的开发者：

```bash
npx @openhands/agent-canvas
```

首次运行会下载运行服务的 Python 包。成功启动后，在浏览器访问 [http://localhost:8000](http://localhost:8000)。

### 从源码运行

```bash
npm install
npm run dev
```

该模式适合修改 Thingo Code 前端。它默认同时启动 Vite、Agent Server、自动化后端与入口代理。更多选项见[开发指南](./DEVELOPMENT.md)。

## 首次配置

### 语言与身份

首次运行默认显示简体中文。需要英文时，在“设置 → 应用”中切换到 English。

应用内只有一个可选代理：**Thingo Code**。它由 Thingo 开发；内部兼容实现可能使用 OpenHands 技术标识，但不会作为产品身份展示或用于自我介绍。

### 配置 Thingo 大模型聚合平台

1. 打开“设置 → LLM”。
2. 选择 **Thingo 大模型聚合平台** 快捷预设。
3. 输入你的 Thingo API Key。
4. 保存并等待连通性检查完成。

预设将自动填入：

| 项目     | 默认值                            |
| -------- | --------------------------------- |
| 模型     | `openai/deepseek-v4-flash`        |
| Base URL | `https://uniapi.thingo.com.cn/v1` |

如果你的 API Key 有其他模型权限，可在高级设置中更改模型 ID。不要把 API Key 写进项目代码、提交记录、`.env` 示例或截图。

### 选择工作区

新建会话时选择一个你信任且希望代理访问的目录。Thingo Code 可以读取和修改该目录中的文件，也可能按任务需要执行终端命令或调用网络服务。

建议：

- 每次只选择当前任务需要的项目目录。
- 使用 Git 项目并保持可回退的提交点。
- 避免在含有生产密钥、个人隐私文件或无备份数据的目录中直接授权批量修改。

## 完成第一个任务

在输入框写出目标、范围和验收条件。例如：

```text
阅读这个项目的 README 和启动脚本，梳理本地运行流程；
不要修改代码，最后列出潜在的配置风险。
```

随后可通过会话界面完成以下操作：

| 区域          | 用途                                       |
| ------------- | ------------------------------------------ |
| 对话          | 说明目标、查看代理过程和确认下一步。       |
| 文件          | 查看和审阅工作区中的文件改动。             |
| 终端          | 查看命令执行结果，确认耗时或有风险的操作。 |
| Git           | 检查未提交变更、差异和提交历史。           |
| 浏览器        | 在需要网页验证时查看代理使用的浏览器。     |
| 计划/任务列表 | 将复杂任务拆成可检查的步骤。               |

对于删除、覆盖、提交、发布、发送信息或访问生产环境等操作，应在执行前核对代理说明和目标范围。

## 常见问题

### 首次启动停在“正在启动后端服务”

桌面版会使用安装包内的 Python 3.12 与预热缓存。若启动仍失败：

1. 完全退出 Thingo Code 后重新打开。
2. 确认安装目录没有被安全软件隔离 `resources/python`、`resources/uv-cache` 或 `resources/bin`。
3. 查看启动窗口日志；若其中出现 `cp313`、`pydantic-core` 或 `aiohttp` 缺失，请安装包含离线运行时的新版本安装包。
4. 不要通过删除安装目录中的缓存来“重试下载”，否则会失去离线启动能力。

### 图标没有更新

Windows 会缓存快捷方式和任务栏图标。退出应用后，删除旧桌面快捷方式，或先取消固定任务栏图标再重新固定。

### LLM 连接失败

依次确认：

1. API Key 有效且未过期。
2. Base URL 是 `https://uniapi.thingo.com.cn/v1`。
3. 模型 ID 对当前 API Key 已授权。
4. 网络或代理未拦截 HTTPS 请求。

不要在公开问题、日志或截图中附上 API Key。
